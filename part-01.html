Praktik E-Report / Part 01

Instalasi alat dan project

Laravel berhasil dibuka di browser.

Langkah praktik

Kita membuat aplikasi pengaduan: warga mengirim laporan, admin menanganinya. Kerjakan di folder latihan baru. Tutorial ini memakai Windows, PHP 8.4, Laravel 12, Livewire 4, dan MySQL. Selesai berarti aplikasi berjalan lokal; publikasi ke internet dibahas sebagai persiapan di part terakhir.

  1. Pasang Laravel Herd untuk Windows, lalu pilih PHP 8.4. Herd menyediakan lingkungan PHP dan Composer. Buka ulang terminal setelah instalasi.
  2. Pasang MySQL Community Server dan MySQL Workbench. Saat konfigurasi, gunakan port 3306 dan catat password root. Pastikan service MySQL berjalan.
  3. Pasang Visual Studio Code untuk mengedit file. Buka PowerShell, kemudian periksa alat berikut.
php -v
composer --version

Jika perintah tidak dikenali, tutup dan buka PowerShell lagi. PHP menjalankan aplikasi; Composer memasang paket PHP. Buat folder latihan di luar project lama:

cd C:\Users\irsya\Downloads
composer create-project laravel/laravel e-report-belajar "12.*"
cd e-report-belajar
composer require livewire/livewire:"4.4.*"
php artisan serve --no-interaction

Buka localhost:8000. Halaman awal Laravel seharusnya tampil. Tekan Ctrl+C untuk menghentikan server. Buka folder e-report-belajar lewat File → Open Folder di VS Code. Semua perintah berikut dijalankan dari folder ini.

Acuan kode di modul: Laravel 12.70.1 dan Livewire 4.4.8. Patch yang terpasang bisa berbeda. Tampilan akhir memakai CDN, sehingga tidak perlu npm untuk hasil tutorial ini; internet diperlukan saat membuka aplikasinya.

Cek sebelum lanjut

php -v menunjukkan PHP 8.4 dan browser menampilkan halaman Laravel.
