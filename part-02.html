Menghubungkan database

Laravel bisa masuk ke database MySQL.

Langkah praktik

Database adalah tempat menyimpan akun dan laporan. File .env berisi pengaturan komputer kamu.

  1. Buka MySQL Workbench. Buat koneksi ke 127.0.0.1, port 3306, username root, dan password instalasi.
  2. Buka tab SQL baru. Jalankan perintah di bawah dengan tombol petir.
CREATE DATABASE e_report_belajar CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

Buka .env di VS Code. Ubah baris berikut, jangan menambah nama pengaturan yang sama dua kali. Ganti password dengan milikmu. Pertahankan APP_KEY yang sudah dibuat saat instalasi.

APP_NAME=E-Report
APP_URL=http://localhost:8000
APP_LOCALE=id
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=e_report_belajar
DB_USERNAME=root
DB_PASSWORD="password_mysql_kamu"
php artisan config:clear --no-interaction
php artisan db:show --no-interaction

Belum perlu menjalankan migrate ke MySQL. Kita lengkapi rancangan tabel dahulu pada part berikut. Jangan bagikan .env karena berisi password.

Cek sebelum lanjut

db:show menampilkan koneksi MySQL dan nama e_report_belajar; tabel boleh masih kosong.
