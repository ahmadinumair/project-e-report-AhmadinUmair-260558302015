Praktik E-Report / Part 03

Tabel, model, dan relasi

Akun dan laporan punya tempat penyimpanan.

Langkah praktik

Migration membuat struktur tabel. Model membantu membaca dan menyimpan isinya. Satu User memiliki banyak Laporan; pelapor_id menyambungkan laporan ke akun.

php artisan make:model Laporan --migration --factory --no-interaction

Buka kode lengkap di bawah satu per satu. Ganti isi file sesuai judulnya. Khusus migration laporan, gunakan file hasil generator yang berakhiran create_laporans_table.php; angka tanggal tidak perlu sama. Jangan membuat dua migration laporan. Migration users sudah ada: edit file tersebut, tetap pertahankan tabel sessions dan password_reset_tokens.

Kolom judul menyimpan ringkasan, detail menyimpan cerita, tanggal menyimpan tanggal kejadian, foto menyimpan lokasi berkas. Status awal adalah pending. fillable membatasi data yang boleh diisi bersama-sama; role, status, dan pelapor_id ditentukan oleh aplikasi.

Versi ini memakai restrictOnDelete: akun yang masih punya laporan tidak bisa dihapus langsung. Ini berbeda dari cascade pada contoh awal agar laporan tidak ikut hilang.

php artisan migrate --no-interaction
php artisan migrate:status --no-interaction

Kode lengkap

Buka satu file, salin seluruh isinya, lalu simpan ke jalur yang tertera di dalam project latihan. Untuk file yang sudah ada, ganti isinya. File Blade dan konfigurasi boleh dibuat lewat VS Code. Pelajari satu pasangan PHP–Blade dalam satu sesi.

app/Models/User.php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Relations\HasMany;
use Illuminate\Foundation\Auth\User as Authenticatable;
use Illuminate\Notifications\Notifiable;

class User extends Authenticatable
{
    use HasFactory, Notifiable;

    protected $fillable = ['name', 'email', 'password', 'no_whatsapp', 'alamat', 'foto'];

    protected $hidden = ['password', 'remember_token'];

    protected $attributes = ['role' => 'warga'];

    protected function casts(): array
    {
        return ['email_verified_at' => 'datetime', 'password' => 'hashed'];
    }

    public function laporans(): HasMany
    {
        return $this->hasMany(Laporan::class, 'pelapor_id');
    }

    public function dashboardRoute(): string
    {
        return $this->role === 'admin' ? 'admin.dashboard' : 'warga.dashboard';
    }
}
app/Models/Laporan.php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;

class Laporan extends Model
{
    use HasFactory;

    public const STATUSES = ['pending' => 'Menunggu', 'proses' => 'Sedang Diproses', 'selesai' => 'Selesai'];

    protected $fillable = ['judul', 'detail', 'tanggal', 'foto'];

    protected $attributes = ['status' => 'pending'];

    protected function casts(): array
    {
        return ['tanggal' => 'date'];
    }

    public function pelapor(): BelongsTo
    {
        return $this->belongsTo(User::class, 'pelapor_id');
    }

    public function statusDescription(): string
    {
        return match ($this->status) {
            'proses' => 'Pengaduan sedang ditindaklanjuti.',
            'selesai' => 'Pengaduan telah selesai ditangani.',
            default => 'Pengaduan menunggu peninjauan admin.',
        };
    }
}
database/factories/UserFactory.php
<?php

namespace Database\Factories;

use Illuminate\Database\Eloquent\Factories\Factory;
use Illuminate\Support\Facades\Hash;
use Illuminate\Support\Str;

class UserFactory extends Factory
{
    protected static ?string $password;

    public function definition(): array
    {
        return [
            'name' => fake()->name(),
            'email' => fake()->unique()->safeEmail(),
            'email_verified_at' => now(),
            'password' => static::$password ??= Hash::make('Password123!'),
            'no_whatsapp' => '081234567890',
            'alamat' => fake()->address(),
            'role' => 'warga',
            'remember_token' => Str::random(10),
        ];
    }

    public function admin(): static
    {
        return $this->state(fn () => ['role' => 'admin']);
    }

    public function unverified(): static
    {
        return $this->state(fn () => ['email_verified_at' => null]);
    }
}
