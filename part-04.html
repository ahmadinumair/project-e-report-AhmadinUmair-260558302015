Praktik E-Report / Part 04

Kerangka halaman dan pembagian akses

Tampilan dasar dan aturan peran siap digunakan.

Langkah praktik

Layout adalah bingkai halaman yang dipakai berulang. Middleware memeriksa peran pengguna sebelum membuka halaman. Policy memeriksa izin terhadap satu laporan.

Buat file PHP berikut melalui Artisan, lalu ganti isinya memakai kode lengkap di bawah. Untuk Blade, buat folder dan file melalui VS Code sesuai jalur yang tertulis.

php artisan make:middleware EnsureRole --no-interaction
php artisan make:policy LaporanPolicy --model=Laporan --no-interaction
php artisan make:class Livewire/WargaPage --no-interaction
php artisan make:class Livewire/AdminPage --no-interaction
php artisan make:class Support/StoredImage --no-interaction

WargaPage dan AdminPage menjadi induk halaman agar aturan akses tidak ditulis berulang. StoredImage membantu membersihkan foto lama. {{ $slot }} pada layout menjadi tempat isi halaman. Jangan ubah routes/web.php dulu: halaman tujuan belum lengkap.

Kode lengkap

Buka satu file, salin seluruh isinya, lalu simpan ke jalur yang tertera di dalam project latihan. Untuk file yang sudah ada, ganti isinya. File Blade dan konfigurasi boleh dibuat lewat VS Code. Pelajari satu pasangan PHP–Blade dalam satu sesi.

app/Http/Middleware/EnsureRole.php
<?php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

class EnsureRole
{
    public function handle(Request $request, Closure $next, string $role): Response
    {
        abort_unless($request->user()?->role === $role, 403);

        return $next($request);
    }
}
app/Policies/LaporanPolicy.php
<?php

namespace App\Policies;

use App\Models\Laporan;
use App\Models\User;

class LaporanPolicy
{
    public function view(User $user, Laporan $laporan): bool
    {
        return $user->role === 'admin' || ($user->role === 'warga' && $user->id === $laporan->pelapor_id);
    }

    public function create(User $user): bool
    {
        return $user->role === 'warga';
    }

    public function update(User $user, Laporan $laporan): bool
    {
        return $user->role === 'warga' && $user->id === $laporan->pelapor_id && $laporan->status === 'pending';
    }

    public function delete(User $user, Laporan $laporan): bool
    {
        return $this->update($user, $laporan);
    }

    public function changeStatus(User $user, Laporan $laporan): bool
    {
        return $user->role === 'admin';
    }
}

app/Support/StoredImage.php
<?php

namespace App\Support;

use Illuminate\Support\Facades\Storage;

class StoredImage
{
    public static function delete(?string $path, string $directory): void
    {
        if ($path && preg_match('#^'.preg_quote($directory, '#').'/[a-zA-Z0-9]+\.(jpg|jpeg|png|webp)$#', $path)) {
            Storage::disk('public')->delete($path);
        }
    }
}
