Praktik E-Report / Part 06

Mengirim laporan dan foto

Form pengaduan siap menyimpan laporan milik warga.

Langkah praktik

php artisan make:class Livewire/ComplaintForm --no-interaction
php artisan make:livewire Warga/Laporan/Create --class --no-interaction
php artisan storage:link --no-interaction

ComplaintForm menyimpan aturan input yang dipakai juga ketika mengedit. WithFileUploads menangani berkas unggahan. Foto boleh kosong; jika diisi harus JPG, PNG, atau WebP maksimal 2 MB.

Alurnya: isi formulir → validasi → simpan foto → simpan laporan → pindah ke detail. Pelapor diambil dari akun yang sedang login, bukan dari input pengguna. Laporan baru selalu pending.

storage:link menghubungkan penyimpanan foto ke folder public agar gambar dapat tampil. Jika Windows menolak pembuatan symlink, aktifkan Developer Mode atau jalankan terminal sebagai administrator lalu ulangi perintah tersebut.

Kode lengkap

Buka satu file, salin seluruh isinya, lalu simpan ke jalur yang tertera di dalam project latihan. Untuk file yang sudah ada, ganti isinya. File Blade dan konfigurasi boleh dibuat lewat VS Code. Pelajari satu pasangan PHP–Blade dalam satu sesi.

app/Livewire/ComplaintForm.php
<?php

namespace App\Livewire;

use Livewire\WithFileUploads;

abstract class ComplaintForm extends WargaPage
{
    use WithFileUploads;

    public string $judul = '';

    public string $detail = '';

    public string $tanggal = '';

    public $foto;

    protected function validatedData(): array
    {
        $data = $this->validate([
            'judul' => 'required|string|max:255',
            'detail' => 'required|string|max:10000',
            'tanggal' => 'required|date_format:Y-m-d|before_or_equal:today',
            'foto' => 'nullable|image|mimes:jpg,jpeg,png,webp|max:2048',
        ]);
        unset($data['foto']);
        if ($this->foto) {
            $data['foto'] = $this->foto->store('laporan', 'public');
        }

        return $data;
    }
}
app/Livewire/Warga/Laporan/Create.php
<?php

namespace App\Livewire\Warga\Laporan;

use App\Livewire\ComplaintForm;
use App\Models\Laporan;
use App\Support\StoredImage;
use Illuminate\Contracts\View\View;

class Create extends ComplaintForm
{
    public function mount(): void
    {
        $this->tanggal = today()->format('Y-m-d');
    }

    public function save(): void
    {
        $this->authorize('create', Laporan::class);
        $data = $this->validatedData();
        try {
            $laporan = new Laporan($data);
            $laporan->pelapor()->associate(auth()->user());
            $laporan->status = 'pending';
            $laporan->save();
        } catch (\Throwable $exception) {
            StoredImage::delete($data['foto'] ?? null, 'laporan');
            throw $exception;
        }
        session()->flash('success', 'Pengaduan berhasil dikirim. Kami akan segera meninjaunya.');
        $this->redirectRoute('warga.laporan.show', ['laporan' => $laporan->id]);
    }

    public function render(): View
    {
        return view('livewire.warga.laporan.create')->title('Buat Pengaduan');
    }
}
