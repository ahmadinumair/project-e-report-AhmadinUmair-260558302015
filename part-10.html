Praktik E-Report / Part 10

Pengujian, perbaikan error, dan selesai

Hasil belajar diperiksa dan siap didemonstrasikan.

Langkah praktik

Lakukan pengecekan ini di browser dengan dua akun warga yang berbeda dan satu admin:

  1. Warga A mengirim laporan tanpa foto, lalu dengan foto yang valid. Keduanya harus tersimpan.
  2. Coba kirim judul kosong dan foto lebih dari 2 MB: formulir harus menolak.
  3. Warga B mencoba URL detail laporan A: akses harus ditolak.
  4. Warga A mengedit dan menghapus laporan percobaan yang masih pending.
  5. Admin memproses laporan lain. Setelah itu warga tidak boleh mengedit atau menghapusnya.
  6. Admin menyelesaikan laporan. Periksa riwayat, pencarian, profil, logout, dan tampilan layar kecil.

Untuk pengujian otomatis, salin file pendukung di bawah. Pengujian memakai SQLite dalam memori, sehingga ekstensi pdo_sqlite harus aktif. Instal PHPUnit yang sesuai dengan kode pengujian:

composer require --dev phpunit/phpunit:"12.5.*" --with-all-dependencies
php artisan test --compact tests/Feature/EReportTest.php
php artisan view:cache --no-interaction
php artisan view:clear --no-interaction

Error umum: Access denied → periksa user/password MySQL di .env. Unknown database → buat database dengan nama yang sama. could not find driver → aktifkan pdo_mysql atau pdo_sqlite sesuai koneksi, lalu buka ulang terminal. 419 → muat ulang halaman dan login lagi. View not found → cocokkan nama file Blade. Foto tidak muncul → periksa storage:link. Tampilan polos → periksa internet karena CSS memakai CDN.

Selesai! Aplikasi lokal sudah mencakup akun warga, pengaduan, foto, riwayat, profil, dashboard, dan penanganan admin. Sebelum dipublikasikan: siapkan hosting PHP/MySQL, arahkan web root ke public, gunakan HTTPS, APP_DEBUG=false, backup database, aset CSS hasil build, dan penyimpanan foto privat. Foto pada versi latihan ini bisa diakses siapa saja yang mengetahui URL-nya.

Kode lengkap

Buka satu file, salin seluruh isinya, lalu simpan ke jalur yang tertera di dalam project latihan. Untuk file yang sudah ada, ganti isinya. File Blade dan konfigurasi boleh dibuat lewat VS Code. Pelajari satu pasangan PHP–Blade dalam satu sesi.

namespace Database\Seeders;

use App\Models\Laporan;
use App\Models\User;
use Illuminate\Database\Seeder;

class DemoSeeder extends Seeder
{
    public function run(): void
    {
        if (! app()->environment('local', 'testing')) {
            throw new \RuntimeException('Data demo hanya boleh dibuat di lingkungan lokal atau testing.');
        }
        User::factory()->count(5)->create()->each(function (User $user): void {
            foreach (['pending', 'proses', 'selesai'] as $status) {
                Laporan::factory()->for($user, 'pelapor')->create(['status' => $status]);
            }
        });
    }
}

    public function test_registration_creates_and_authenticates_only_a_citizen(): void
    {
        Livewire::test(Auth\Register::class)
            ->set('name', 'Ayu Warga')->set('email', 'AYU@example.test')
            ->set('no_whatsapp', '081234567890')->set('alamat', 'Jalan Melati 10')
            ->set('password', 'Password123!')->set('password_confirmation', 'Password123!')

        $this->assertSame('warga', $user->role);
        $this->assertSame('ayu@example.test', $user->email);
